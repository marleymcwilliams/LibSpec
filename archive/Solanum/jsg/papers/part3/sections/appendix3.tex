\subsection{Acceptance checks (Appendix A)}\label{app:resolution-accept}
\begin{acceptchecks}
\item \textbf{No unresolved refs:} the compiled PDF contains no bold “\textbf{??}”. CI fails otherwise.
\item \textbf{Safe-macro integrity:} every cross-doc reference in Tab.~\ref{tab:master-resolution} appears via \texttt{\textbackslash jsgi*}/\texttt{\textbackslash jsgii*} macros (never raw labels), so broken imports render visibly.
\item \textbf{Rule-index coverage:} Table~\ref{tab:rule-index} includes each Rule referenced in the text; every Rule appears in at least one acceptance check or KPI guard, and each is cited by at least one downstream consumer in Tab.~\ref{tab:contract-deps}.
\item \textbf{Guard order proof-print:} for any audited window, the Tier-1 pack carries a \texttt{proof\_print\_id} that linearly encodes EF $\rightarrow$ DRO $\rightarrow$ PR $\rightarrow$ CBF consumption with the exact guard verdict/witness ids (Prop.~\ref{prop:guard-top}); replays must bit-match.
\item \textbf{Traceability:} auditors can traverse Tab.~\ref{tab:contract-deps} from any runtime Rule to (i) its foundational deps (safe refs) and (ii) the downstream invariant where it is consumed; missing links fail CI.
\end{acceptchecks}
