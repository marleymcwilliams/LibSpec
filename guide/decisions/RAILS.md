The four normative rails are declared values in the Norm layer, and no gate enforces them in v1, because their inputs don't exist yet and a fail-closed gate would reject everything. A rail can enter later as a must-fail class once it has a precise statement, real inputs, a mutant and a witness instance, and the must-pass set still passes; that is a tightening and needs no weakening record. Must-fail classes are hard floors: runtime weakenings can't touch them, and removing one takes a new statements version with a CHANGELOG line marking the weakening. Persistent weakenings: not yet. No v1 statement depends on them, so the choice between a refill rate, a duration cap and escalating renewal cost moves to the milestone that states the token bucket.
