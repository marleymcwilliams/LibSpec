# (a) Geometric diagnosis — DEC/Hodge split, dwell, holonomy, Fisher continuity

**Goal:** Keep the five invariants intact with explicit margins and proofs, but **fortify the interfaces** where model ↔ world mismatches arise.

## A1. Invariants & operating bounds (enforced)

- **I₁ No-Zeno dwell at frontiers**
    
    - Minimum dwell `τ_min` computed with **conservative CI** on normal speed `ν̂_min` and saltation bound `C_salt`, with multiplicative safety factor `γ_dwell ≥ 1.5`.
        
    - Dwell escalation becomes **non-decreasing** over a 21-day horizon (τ*), and **cannot be relaxed** without human dual-control sign-off (see governance).
        
- **I₂ Statistical locality & provenance continuity**
    
    - EF radius `r = ε_EF/L_ψ` is estimated with **sandwich bounds** and **out-of-band shift monitors** (kernel two-sample + HSIC) that do **not** depend on the Fisher metric.
        
    - Continuity pack target: ≤5% MAPE, moments up to k=4, **CVaR₀.₉₅** preserved.
        
- **I₃ Identifiability-first discovery (correlation ≠ coupling)**
    
    - Promotions require **pre-registered dependence tests** (HSIC with FDR control) **and** an **instrument/lag structure** check. Discovery α=0.05, β=0.2; coupling triggers at `ρ≥0.6` or Kendall-τ≥0.5 **or** HSIC p<0.01 after FDR.
        
- **I₄ Actuation-basis stability**
    
    - **Holonomy** and **Harmonic Rotational Mass** budgets retained **as budgets**, but add **imminent degeneracy sentinels** (min spectral gap `λ_gap` and condition number `κ(A)` bounds) to catch rapid basis collapse **before** budgets are consumed.
        
- **I₅ Rights-plane & PR stability**
    
    - Runtime **CBF/CLF-QP** enforced with barrier certificates; **band-limited PR** witness (GKYP) is **non-waivable** and scoped to a formal **uncertainty set Ω** (see C7).
        
    - **Default-deny** backpressure: missing/invalid telemetry ⇒ lock.
        

## A2. Anti-Goodhart stance (metric vs. target)

- Treat **Coupling Mass** `M_t = κ_tᵀ F_t^{-1} κ_t` as a **diagnostic**, not a direct optimization target.
    
- Add **meta-guard**: if `M_t` drops without corroborating change in external process variables or test power, set `Clamp=Amber` and require operator review.
    

## A3. Anti-normalization-of-deviance

- All threshold relaxations (e.g., grazing `p_thr`) require:  
    (i) risk memo + simulation evidence, (ii) **dual approval** (safety champion + domain lead), (iii) a **reversion timer** ≤ 21 days.
    
- Provenance records include **`threshold_change_digest`** and justification.

```python
import json, time
import psycopg2
from psycopg2.extras import Json

def get_state(conn, key):
    with conn, conn.cursor() as cur:
        cur.execute("SELECT val, version, updated_at FROM pipeline_state WHERE key=%s FOR SHARE", (key,))
        row = cur.fetchone()
        return (row[0], row[1], row[2]) if row else ({}, 0, None)

def cas_update(conn, key, expect_version, update_fn, retry_max=8):
    backoff = 0.02
    for _ in range(retry_max):
        try:
            with conn:
                with conn.cursor() as cur:
                    cur.execute("SELECT val, version FROM pipeline_state WHERE key=%s FOR UPDATE", (key,))
                    row = cur.fetchone()
                    val, ver = ({}, 0) if not row else (row[0], row[1])
                    if ver != expect_version:
                        return False, ver, None
                    new_val = update_fn(val)
                    cur.execute("""
                        INSERT INTO pipeline_state AS t (key, val, version)
                        VALUES (%s, %s, %s)
                        ON CONFLICT (key) DO UPDATE
                        SET val=EXCLUDED.val, version=t.version+1, updated_at=now()
                        RETURNING version
                    """, (key, Json(new_val), ver))
                    new_ver = cur.fetchone()[0]
                    return True, new_ver, new_val
        except psycopg2.Error:
            time.sleep(backoff); backoff = min(backoff*2, 0.5)
    raise RuntimeError("E_STATE_LIVENESS")
```

## C4. Out-of-band shift monitors (independent of Fisher)

**`monitors/oob_shift.py`**

```python
import numpy as np

def rbf_kernel(x, y=None, gamma=None):
    y = x if y is None else y
    if gamma is None: gamma = 1.0 / (x.shape[1] or 1)
    d = np.sum((x[:,None,:]-y[None,:,:])**2, axis=-1)
    return np.exp(-gamma * d)

def hsic_stat(X, Y, gamma_x=None, gamma_y=None):
    n = X.shape[0]
    K = rbf_kernel(X, gamma=gamma_x)
    L = rbf_kernel(Y, gamma=gamma_y)
    H = np.eye(n) - np.ones((n,n))/n
    KH = H @ K @ H; LH = H @ L @ H
    return (1/(n-1)**2) * np.sum(KH*LH)

def mmd_u_stat(X, Y, gamma=None):
    Kxx = rbf_kernel(X, X, gamma); Kyy = rbf_kernel(Y, Y, gamma); Kxy = rbf_kernel(X, Y, gamma)
    n, m = X.shape[0], Y.shape[0]
    return (np.sum(Kxx)-np.trace(Kxx))/(n*(n-1)) + (np.sum(Kyy)-np.trace(Kyy))/(m*(m-1)) - 2*np.sum(Kxy)/(n*m)
```

**VC issuance/verification**

**`provenance/vc.py`**

```python
import json, time, hashlib
from crypto.ed25519 import sign, verify, export_pubkey

def canonical(obj): return json.dumps(obj, sort_keys=True, separators=(",",":")).encode()

def issue_vc(issuer_pk_hex:str, sk, typ:str, claims:dict, expires_s:int=86400):
    vc = {
        "type": typ,
        "issuer_pk": issuer_pk_hex,
        "iat": int(time.time()),
        "exp": int(time.time()) + expires_s,
        "claims": claims
    }
    payload = canonical(vc)
    vc["sig"] = sign(sk, payload).hex()
    vc["payload_sha256"] = hashlib.sha256(payload).hexdigest()
    return vc

def verify_vc(vc:dict, pk) -> bool:
    if int(time.time()) > vc["exp"]: return False
    payload = {k:vc[k] for k in ("type","issuer_pk","iat","exp","claims")}
    return verify(pk, canonical(payload), bytes.fromhex(vc["sig"]))
```

**Merkle bundle**

**`provenance/merkle.py`**

```python
import hashlib, math

def leaf_hash(b:bytes)->bytes: return hashlib.sha256(b"\x00"+b).digest()
def node_hash(l:bytes,r:bytes)->bytes: return hashlib.sha256(b"\x01"+l+r).digest()

def merkle_root(leaves: list[bytes]) -> str:
    if not leaves: return hashlib.sha256(b"").hexdigest()
    layer = [leaf_hash(b) for b in leaves]
    while len(layer)>1:
        nxt=[]
        for i in range(0,len(layer),2):
            a=layer[i]; b=layer[i+1] if i+1<len(layer) else a
            nxt.append(node_hash(a,b))
        layer=nxt
    return layer[0].hex()
```
