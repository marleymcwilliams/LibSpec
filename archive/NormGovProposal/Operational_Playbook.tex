\section{Continuous Thread (Speed as a Live Metric)}
We treat Generation and Inversion as endpoints of a single strand with modes:
\begin{enumerate}
  \item \textbf{Spark (Propose)}: Compose a proposal; list SPEC anchors to update; enumerate new must-fails with reason codes.
  \item \textbf{Stabilize (Align)}: Align across Living Doc and Master Plan; ensure SSOT pointers \& coverage entries exist.
  \item \textbf{Harden (Govern)}: Attach guards, classes, approval chains; wire negative controls; verify Gate-0 \& CI.
  \item \textbf{Prove (Invert)}: Emit receipts; run negatives; demonstrate replay under EnvLock; show trace reconstruction.
  \item \textbf{Integrate (Land)}: Small PR; advance phase gate; update snapshots.
\end{enumerate}

\section{Workflow: Recipes \textrightarrow{} Contracts \textrightarrow{} Gates}
\subsection{Compose with ResearchHub}
Recipes: alignment, agentic-guided execution, iterative change. Inject scope labels, pre-commit output, and optional repo ZIP. Outputs include SPEC anchors to update and explicit must-fail reason codes.

\subsection{Map to JSGI Layer Contracts (Quick Check)}
\begin{itemize}
  \item \textbf{Rep/Alg}: stratified/Filippov setting; budget frontier dwell time $\tau_{\min}$ and defect $C_{\mathrm{fr}}$.
  \item \textbf{Stoch/Inf}: finite dictionaries within EF radius; whitened cumulants.
  \item \textbf{Clos}: DRO soft-transport; KKT stationarity; adaptive radius policy.
  \item \textbf{Ctrl}: Dirac projections; PR checks; ISS margins and freeze windows.
  \item \textbf{Comp}: non-expansive functors; Lipschitz constants in FIM metric.
\end{itemize}

\subsection{Land via WorkCards (Guards \& Evidence)}
Declare precise \textit{Admits/Emits/Guards/FailFast/Links}; evaluate guards over canonical inputs \& policy digests.
Each execution emits a \code{ReceiptEnvelope/v1} bound by \code{checker_hash} $\in$ EnvLock.

\subsection{Phase Gates (Now \textrightarrow{} Next)}
\begin{itemize}
  \item \textbf{PR-D} Saga/Compensation: all side-effecting tools declare compensation; negative \code{tool_missing_compensation}.
  \item \textbf{PR-E} LLM I/O Envelope: typed envelope, rounding receipts; negatives \code{llm_missing_receipt}, \code{llm_untyped_io}.
  \item \textbf{PR-F/G/H}: SSOT tooling; UpdateCert generator; formal ResearchLoop with ``ideas-as-prose'' negative.
\end{itemize}

% =====================================================
\section{Speed Governance (Adjusting Pace Safely)}
\subsection{When to Slow}
Crossing frontiers or changing controller bands: consult $\tau_{\min}$ and $C_{\mathrm{fr}}$; apply freeze windows; verify ISS margins. New approximations: enforce rounding receipts; stay within EF radius; use windowed cumulants for drift.
\subsection{When to Accelerate}
SSOT pointers present; Gate-0 clean; negatives failing for intended reasons; receipts reproducible under EnvLock; closure policy certified and composition non-expansive.

\section{Checklists}
\subsection{Proposal (Spark)}
\begin{itemize}
  \item Recipe rendered (attach output)
  \item SPEC anchor(s) to update listed (path/digest)
  \item New negative(s) + reason\_code(s) enumerated
\end{itemize}
\subsection{Alignment (Stabilize)}
\begin{itemize}
  \item Living Doc snapshot updated
  \item Master Plan acceptance bars linked
  \item SSOT pointers verified (no prose duplication)
\end{itemize}
\subsection{Governance (Harden)}
\begin{itemize}
  \item WorkCard fields complete
  \item Governance class \& approval\_chain wired; policy\_version pinned
  \item Negative(s) created and added to coverage
\end{itemize}
\subsection{Proof (Invert)}
\begin{itemize}
  \item ReceiptEnvelope/v1 emitted; \code{checker_hash} $\in$ EnvLock
  \item Negatives fail for intended reasons (Gate-0 \& CI)
  \item Replay passes under declared portability stance
\end{itemize}
\subsection{Land (Integrate)}
\begin{itemize}
  \item Small PR only; diffs reference SPEC anchors/tests
  \item Phase gate progress recorded in Master Plan
\end{itemize}
