\section{Evidence Packs, Provenance Ladder, and Benchmarks (v2)}\label{sec:pcc-bench-v2}

\paragraph{Objective.}
Make every claim \emph{replayable}. We promote Tier-1…4 artifacts to strict schemas with REQUIRED fields, define a stable \emph{proof print} (guard order: EF$\rightarrow$DRO$\rightarrow$PR$\rightarrow$CBF$\rightarrow\omega$), mandate solver fingerprints and tolerances, propagate clamp/quarantine states through the Ladder, fix a KPI row schema consumed by $\omega$-automata, and publish a benchmark suite with reference runs.

\paragraph{Tier-2 (Provenance Ladder).}
Hash-chain telemetry\,$\rightarrow$\,features\,$\rightarrow$\,cumulants\,$\rightarrow$\,FDR\,$\rightarrow$\,MTC/IV\,$\rightarrow$\,calibrations (saltation/DK)\,$\rightarrow$\,QP/PR\,$\rightarrow$\,clamp/quarantine\,$\rightarrow$\,registries with: (i) mirrored signed sources; (ii) parity checks (MAPE \(\le 5\%\) for \(k\!\le\!4\) moments; CVaR\(_{0.95}\) preserved); (iii) row-hashes consumed by automata. \uses{\jsgiiSec{\lblSchemas}; Def.~\ref{def:tierpacks}.}

One row per promotion with BY\-\(p\), MTC transcript (power), SPRT transcript linked to \texttt{sprt\_params}, clamp=Green, IV-badge. \uses{Rule~\ref{rule:promotion}; Prop.~\ref{prop:cis}.}

\subsection{Deterministic replay, proof prints, and solver transcripts}\label{subsec:det-replay}
\emph{\layertag{Comp/Rep}}

\textbf{Proof print.} Each window emits a compact card with stable IDs in guard order:
\[
\big[\ \texttt{ef\_guard\_id}\ \rightarrow\ \texttt{dvdrho\_id}\ \rightarrow\ \texttt{pr\_witness\_id}\ \rightarrow\ \texttt{cbf\_audit\_id}\ \rightarrow\ \texttt{switch\_stability\_id}\ \big].
\]
Determinism \(=\) (container SHA) \(+\) (seeds) \(+\) (solver settings). QP/GKYP/DRO transcripts log algorithm, version, tolerances, iteration caps, status, dual/primal residuals. Replays must match numeric fingerprints within \emph{absolute} \(1\!\times\!10^{-12}\) \emph{or} \emph{relative} \(1\!\times\!10^{-9}\); larger deltas require an explicit vendor/BLAS justification. \uses{\jsgiiSec{\lblSchemas}; Prop.~\ref{prop:pr-consume}; Def.~\ref{def:pinned-env}.}

\subsection{Clamp \& quarantine propagation in the Ladder}\label{subsec:ladder-prop}
\emph{\layertag{Inf/Comp}}

The Ladder carries \texttt{clamp\_state} and \texttt{quarantine\_bit}. Downstream consumers must check: (i) CIS rows originate from windows with clamp=Green and \texttt{quarantine\_bit}=0; (ii) automata reject any run that consumes a quarantined row; (iii) KPI printers tighten \((\cutq,r)\) when sustained Yellow/Red is present. \uses{Rule~\ref{rule:dvdrho}; Rule~\ref{rule:ef-clamp}; Prop.~\ref{prop:cis}.}

\subsection{Benchmark suite and reference runs}\label{subsec:bench}
\emph{\layertag{Comp/Inf/Ctrl}}

We publish five canonical benchmarks; each ships a reference replay pack and a target acceptance profile.

\begin{enumerate}[leftmargin=*]
\item \textbf{Negative control.} Stationary data; expected: clamp stays Green; $|E_t|$ nonincreasing; promotions=0; PR margin stable; $\mathrm{CVaR}_{0.95}\!\ge\!0$. Include proof prints and KPI hashes.
\item \textbf{Frontier grazing stress.} Inject controlled grazes; expected: dwell escalation + tube freeze; saltation replay passes; zero rights violations; $C_{\text{salt}}$ CI present.
\item \textbf{Degeneracy collapse.} Shrink spectral gap; expected: HarmMass rises; basis updates blocked; CQLF or enforced $\tau_{\min}^{\mathrm{sw}}$; PR auto-shrink certifies.
\item \textbf{Confounded IV.} Context-dependent exclusion breaks; expected: IV-badge \emph{denied}; no promotion; realized FDR within budget.
\item \textbf{Model drift (Red clamp).} Drive $\chi>\constref{chiR}$; expected: fail-closed to HSIC/CVaR-only; promotions frozen; $\omega$-automata still accept rights/specs.
\end{enumerate}

Each benchmark includes: container SHA, seeds, solver transcripts, Tier-1 pack (Tab.~\ref{tab:tier1-schema}), KPI schema version, and accepted/rejected $\omega$-run with identical first counterexample hashes where applicable.

\subsection{Acceptance checks for evidence and benchmarks}\label{subsec:pcc-accept}
\begin{acceptchecks}
\item \textbf{Tier-1 completeness:} every consumed window has a Tier-1 pack that satisfies Tab.~\ref{tab:tier1-schema}; \texttt{proof\_print\_id} present; CI fails on any missing REQUIRED field.
\item \textbf{Deterministic replay:} re-execution with \texttt{replay\_pack\_sha} and \texttt{seeds} reproduces solver fingerprints within abs \(1\!\times\!10^{-12}\) or rel \(1\!\times\!10^{-9}\); deviations carry explicit justification (Subsec.~\ref{subsec:det-replay}).
\item \textbf{Proof print order:} the guard sequence in the proof print matches EF$\rightarrow$DRO$\rightarrow$PR$\rightarrow$CBF$\rightarrow$\omega$ and the IDs are consistent with Tier-1 and KPI rows.
\item \textbf{KPI schema integrity:} KPI rows match Table~\ref{tab:kpi-schema} and hash to the logged \texttt{kpi\_row\_hash}; automata acceptance/rejection reproduces the reference profile (Subsec.~\ref{subsec:automata}, \ref{subsec:bench}).
\item \textbf{Clamp/quarantine propagation:} any CIS row consumed by automata has clamp=Green and \texttt{quarantine\_bit}=0; violations cause automata rejection (Subsec.~\ref{subsec:ladder-prop}).
\item \textbf{Benchmark reproducibility:} shipped packs for the five benchmarks replay with identical first counterexample hashes on the documented rejects (Subsec.~\ref{subsec:bench}).
\end{acceptchecks}
